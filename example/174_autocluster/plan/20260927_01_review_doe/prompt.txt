Schlage vor, wie wir dieses Feature implementieren können. (schreibe
deinen code in cl-py-generator/example/174_autocluster). schreibe
zunaechst erstmal reines python und nutze nicht den lisp to python
transpiler. Habe ich alle Requirements aufgelistet, die wichtig sind,
oder kannst du dir vorstellen, dass noch andere Dinge werden sollen?
Liste mir diese auf Vorschlägen, was man am besten umsetzen könnte.

Schreibe einen deutschen Implementierungsplan. Dieser
Implementierungsplan soll einen unabhängigen AI-Agenten dazu
befähigen, selbstständig einen Kontext aufzubauen, der die
wesentlichen quellen beinhaltet.  Gern darfst du auch architektur
diagramme als ascii oder mermaid (so dass es gut auf github angezeigt
wird) erzeugen. denn auch ein mensch soll anhand der dokumente einen
guten ueberblick ueber das thema bekommen.  Das heißt, der
Implementierungsplan hat eine Liste von Dateien, die sich der Agent
sich anschauen sollte, mit einer kurzen Beschreibung für jede Datei.
Weiterhin soll der Implementierungsplan eine Erklärung Commit Messages
sendet werden sollen. Und zwar sollen diese mit einer umfassenden
Beschreibung und als Conventional Commit format ausgeführt werden.

Neue Unit-Tests und Integration-Tests sollen wie erforderlich
eingeführt werden.  Diese sollen auch ausgeführt werden.

schreibe task.md wo du die implementierungs und test schritte
aufeinander abfolgen laesst, so dass ein agent die tasks seriell
abarbeiten kann und die arbeit in jedem schritt getested und validiert
wird. jeder modus bekommt eigene tasks (implementierung, host-tests).

Nach der vollständigen Implementierung, wenn alle Tests abgeschlossen
sind und alles committed ist, soll auch ein Walkthrough-Dokument
entgeschrieben werden und in plan/2026.../walkthrough.md (wo auch
dieses prompt.txt liegt) abgelegt werden. Dieses soll auf deutsch
zusammenfassen, was wirklich implementiert wurde, welche Stellen
aufgrund der Tests oder wie auch immer gemacht wurden, als im
Untergrund auch Learnings und mögliche Erweiterungen. liste auch die
neuen programme die mit in den docker container aufgenommen werden
sollten

insbesondere in den walkthrough dokumenten musst du den leser abholen
und mitnehmen. schreibe eine ordentliche einfuehrung in das
dokument. definiere scope des experiments, die methoden und am ende
schreibe eine conclusion wie in einem wissenschaftlichen paper oder
technischen dokument
